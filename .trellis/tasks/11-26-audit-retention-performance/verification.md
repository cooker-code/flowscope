## 同一数据集 HTTP 耗时

环境：macOS arm64、本机 cargo debug serve、循环地址 HTTP；652,188 条合成审计，SQLite 文件约 2.80GB，每行另含 2KiB 解析载荷。每项预热一次后取 5 次中位数。旧版基线 754390a0；新版查询版本只在缺失事件回退上有后续修正，该样本没有缺失事件，因此沿用仍适用的查询结果。

| 查询 | 旧版，652,188 条 | 新版，同样条数 | 新版，7 天清理后 |
| --- | ---: | ---: | ---: |
| 普通首页 | 12.10 ms | 13.12 ms | 6.81 ms |
| SELECT 筛选 | 6165.43 ms | 13.99 ms | 4.74 ms |
| SELECT 第 100 页 | 6960.29 ms | 14.06 ms | 4.43 ms |
| 近 7 天 | 3.51 ms | 3.13 ms | 3.76 ms |
| SELECT + 近 7 天 | 599.23 ms | 3.22 ms | 3.55 ms |
| 已入图筛选 | 594.77 ms | 9.40 ms | 4.85 ms |
| SELECT + 已入图 | 678.08 ms | 352.81 ms | 25.41 ms |
| 调用方自己的 SELECT | 600.07 ms | 321.35 ms | 14.45 ms |

8 组查询在相同数据下的精确总数及页面 ID 完全一致。普通首页原本已经较快，纯查询优化后的约 1ms 差异不构成明确改善；主要收益来自类型和状态筛选。
